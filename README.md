# JCIFS
The Java CIFS Client Library

This is the original JCIFS package which used to be hosted at jcifs.org and before that at jcifs.samba.org.

## Download

If you're just looking for the jCIFS jar, this is the place to get it.
Prebuilt binaries are available under Releases:

  https://github.com/ioplex/jcifs/releases

# IMPORTANT

This code is completely obsolete. It only supports SMB1 which has been disabled in Windows for a very long time.
It's also completely unpatched for many years.
Fortunately there are multiple alternatives:

- jcifs-ng
- smbj
- jcifs-codelibs
